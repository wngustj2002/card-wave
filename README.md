# CARDWAVE — AI 카드뉴스 스튜디오

## 배포 방법

### 1. Vercel에서 환경변수 설정
- Vercel 프로젝트 → Settings → Environment Variables
- `ANTHROPIC_API_KEY` = Anthropic API 키 입력

### 2. Anthropic API 키 발급
- https://console.anthropic.com 접속
- API Keys → Create Key → 복사

### 3. 완료
배포 후 자동으로 https://cardwave-xxx.vercel.app 주소 생성
